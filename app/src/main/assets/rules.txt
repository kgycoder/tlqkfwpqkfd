# 맞춤법 규칙 사전 (오프라인)
# 형식:  정규식 => 교정 결과 => 이유
#   - 교정 결과에서 $1, $2 는 정규식의 괄호 그룹을 뜻합니다.
#   - '#' 로 시작하는 줄은 주석입니다.
#   - 앞 음절의 받침 조건이 필요한 규칙(-ㄹ게, -ㄹ 거, -ㄹ 수 있다)은 SpellEngine.kt 에 있습니다.
# 규칙을 추가하려면 이 파일에 한 줄만 더하면 됩니다.

# ---------- 되 / 돼 / 안 / 않 ----------
됬 => 됐 => '되었'의 준말은 '됐'이에요
(?<![가-힣])안되요 => 안 돼요 => '안 되어요'의 준말은 '안 돼요'예요
(?<![가-힣])안되서 => 안 돼서 => '안 되어서'의 준말은 '안 돼서'예요
되요 => 돼요 => '되어요'의 준말은 '돼요'예요
되서 => 돼서 => '되어서'의 준말은 '돼서'예요
뵈요 => 봬요 => '뵈어요'의 준말은 '봬요'예요
(?<![가-힣])안돼 => 안 돼 => '안'은 부사라 뒤 말과 띄어 써요
(?<![가-힣])안되(?=는|면|고|지|니|네) => 안 되 => '안'은 부사라 뒤 말과 띄어 써요
않되 => 안 되 => 부정 부사는 '않'이 아니라 '안'이에요
않돼 => 안 돼 => 부정 부사는 '않'이 아니라 '안'이에요
([가-힣])야(되|돼) => $1야 $2 => '해야 되다'처럼 띄어 써요
([가-힣])지않 => $1지 않 => '않'은 앞말과 띄어 써요
지 안(?=았|는|고|으|습|네|아요) => 지 않 => '-지 않다'가 맞아요
지 안다(?![가-힣]) => 지 않다 => '-지 않다'가 맞아요
